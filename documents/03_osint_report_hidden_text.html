Exercise parcel SMS wave in the exercise area

This is an open-source report from a public security blog. It is invented for a training exercise. The blog says that many people in the exercise area got a text message about a parcel that was not delivered.

The message asks the person to pay a small delivery fee. The link in the message opens a login page used in the trick. The page copies the user name, the password and the card number that the person types.

Indicators of compromise (IOCs) in the report: the web addresses track-parcel.example and parcel-fee.example, and the sender name "PARCEL-INFO". These are exercise values.

Tactics, techniques and procedures (TTPs): the red cell sends text messages (smishing), uses urgency ("pay today or the parcel goes back"), and copies the look of a real delivery company.

Analyst comment: the source is a public blog, so we cannot fully trust it yet. Check it against a second source before it goes in the INTSUM.
